Dependencias a instalar para correrlo utilizando el cubo:  

        python3 -m venv venv
        source venv/bin/activate
        pip install -r requirements.txt

OBJ: Leer MAVLink directo desde el CubePilot 

        ls /dev/ttyACM*

Configurar .env:

        TAK_SOURCE=mavlink
        MAVLINK_CONNECTION=/dev/ttyACM0
        MAVLINK_BAUDRATE=115200
        TAK_INTERVAL=1

Ejecutar:

        python -m tak_client

Si corres en Windows PowerShell, usar el puerto COM del CubePilot:

        MAVLINK_CONNECTION=COM3
